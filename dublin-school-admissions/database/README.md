# Dublin admissions — populated portable database, milestone 1

This is an actual local SQLite database (`admissions.sqlite3`), not a design proposal, hosted service or shared online database. Open with DB Browser for SQLite, `sqlite3`, Python's standard `sqlite3`, or a compatible analytical tool. No signup required. SQLite gives transactional updates, foreign keys, indexed year/school queries and reproducible snapshots; CSV/JSON remain convenience exports, not the source of truth.

## Model and comparison safety

School identity → document edition → notice → exact school-year/cohort/table group → metric observation → field evidence. Retrievals and originals are separate: a capture timestamp is never a publication date or an admissions year. Same-payload aliases share a document within a school; repeated archive snapshots do not create a new school year. Notice title assertions and publication assertions preserve conflicting interpretations. Historical counts can refer to a different year from the notice title. Original year strings and all source records remain available.

Groups never combine different payload revisions. A selected primary record borrowing history from an older document is partitioned by source payload before normalization. Upcoming and retrospective places are separate observations even when they share a school/year. Cohorts retain exact source labels: Junior Infants, senior grades, special classes and specific needs labels are not forced into one intake. Mixed/ambiguous/joint cohorts are flagged and not presented as comparable. Strict exact-label cohort identity can under-match genuinely equivalent differently worded cohorts; reviewed equivalence mapping is preferable to automatically merging them.

`offers`, `acceptances` and `actual_admissions` are different metrics. Explicit waiting-list offers/acceptances, names placed, remaining/snapshot quantities, unspecified lists, reoffers and other-school removals are separate definitions. No waiting-list movement is calculated by subtraction. Interest registrations and eligible-only/base-excluding-late application quantities are not silently converted into all applications. Source-supported category sums present in the legacy raw data remain traceable but do not qualify as directly printed aggregate figures without explicit field evidence. The strict view currently has52 complete five-metric source groups; this lower count than legacy completeness figures reflects these stricter rules and payload partitioning, not deletion of the398 historical tables.

Null is not zero. Observations carry `value_status`; unsupported/absent fields remain null or non-comparable. `not_published`, `not_found`, `not_applicable`, `ambiguous`, `blocked`, `not_attempted`/pending and `not_recorded` are separate concepts across metric, coverage and collection layers. Exact legacy reason strings are retained; absence from a bounded search never proves non-publication. New source-year conflicts are stored undated rather than assigned a guessed previous year.

`v_group_funnel` never stitches groups. `v_comparison_ratios` computes ratios only for evidence-supported values with explicit years, matched cohort scope, no within-group value conflict and valid positive denominator. Missing components stay null. `v_preferred_comparable` picks a **whole group**, deterministically, by explicit dating/scope, conflicts, evidence quality, selected-source status, supported-field count and stable ID. It does not pick the best-looking value separately for each field, and is not a claim that an undated revision was published later. `v_preferred_with_lineage_quality` flags disagreement across editions and returns raw/source IDs. Analysts should normally exclude or inspect `cross_edition_conflict=1`. Upcoming/retrospective/snapshot/criterion scopes remain distinct. `v_year_on_year` only computes deltas for consecutive years within the same exact cohort/table scope.

Application/place ratios measure recorded applications per published place, NOT unique children, unmet local demand, school quality, a catchment or an admission probability. One child may apply to multiple schools; periods, late applications and eligibility definitions vary. Read qualifiers and source evidence.

## Metadata and future sources

School locations retain address/Eircode, coordinates, CRS, source, source-asof precision and an explicit boundary/catchment caveat. Ethos, teaching language, gender and patronage appear as null unless actually sourced: none is inferred from a name, school abbreviation or location. Historical identity links do not establish equivalence of admissions catchments.

Empty normalized geographic-area, external-dataset, geographic/time/age-band observation and development/inspection tables are ready for future CSO small-area cohort population, housing completions/developments and property-price aggregates. They are deliberately unpopulated; no external enrichment or fabricated population/property data was added.

## Collection progress

The low-rate resumable all-school archive index queue was started after local triage. Original-school historical archive navigation has its own explicit per-school pending queue, distinct from already completed v4 current-notice research. It searches all available archive dates without an earliest-year cutoff and paginates bounded requests; domain coverage is logged separately from verified school-year notice coverage. An indexed status200 capture is a **candidate**, not proof a PDF can be replayed or contains a notice. `exports/archive_progress.json`, `exports/work_queue.csv` and `checkpoints/archive_index/` state the exact release snapshot and failures. A three-consecutive-timeout circuit breaker pauses rather than hammering the archive; inspect the log/STOP files before resuming. No proxy/network refusal or access challenge is bypassed. The prior pilot's successfully replayed bodies remain imported separately.

After diagnosing/cooling down transient failures, `archive_index_worker.py` resumes unsatisfied domains and pagination from checkpoints. Do not resume past `STOP_ARCHIVE_ACCESS.json`; that requires an authorized access resolution, not a new route. Robots.txt preflight returned404 at the permitted archive host; no school-host crawl or school contact is performed by the index worker. Large shared hosting domains are deferred for exact school-path scoping instead of indiscriminate host crawling. Indexed captures must next be replayed and evidence-reviewed; neither domain searches nor the archive are exhaustive. Original-school archive navigation remains a pending phase, not falsely marked complete.

## Reproduce and inspect

Run `python import_database.py` for the frozen baseline, then `python review_local_backlog.py` for the frozen local expansion. When running beside the original collection these perform full text/payload checks; `python test_reproduction.py` proves repeat-import idempotency and an isolated offline rebuild; `python validate_database.py` runs integrity/foreign-key/conservation/known-school fixtures and immutable-archive tests. `python sync_archive_queue.py` imports saved index progress without network calls. `queries.sql` contains comparisons, lineage, waiting events, consecutive-year deltas, coverage and spatial-input examples. **Do not run the network worker merely to open the database.**

The supplied database is self-contained for SQL analysis; frozen `inputs/*.json.gz` support raw-import replay. Full original-payload revalidation additionally needs the original parent cache or supplied v4 archive. Minimized source-text references are included for offline normalized-import replay; an actual isolated rebuild reproduced all table counts, core IDs and preferred numeric views. Public field evidence is also embedded in the database. Source-relative paths are provenance, not a claim every original PDF is bundled here.

See `DATA_DICTIONARY.md` for the ER diagram/table dictionary, `migrations/*.sql` for schema/view versions and `POSTGRESQL.md` for migration notes. SQLite is an adequate portable initial foundation; a future PostgreSQL deployment is a separate hosting/access decision, not already provided here.
